## Big idea

The last step of any analysis is getting it to other people. The question is always **what the recipient needs**:

| Recipient needs | Share as |
|---|---|
| To open and explore the workbook in Tableau, with the data | a packaged workbook (`.twbx`) |
| To explore it in a browser, kept up to date | a workbook published to Tableau Server or Tableau Cloud (or Tableau Public) |
| A picture for an email or a report | an image or a PDF |
| Slides for a meeting | a PowerPoint export |
| The numbers themselves | View Data, or an export of the data or a crosstab |

## How it works

### Share a workbook (for example, twbx as a PDF or an image, publish to Tableau Server)

**Packaged workbook (.twbx).** "Select **File > Save As**", then "select **Tableau Packaged Workbooks** on the Save as type drop-down list." A packaged workbook "saves the workbook along with all referenced local file data sources and images into a single file": Excel and text files, extracts (`.hyper`), background images, custom shapes and custom geocoding. Data from a server isn't packaged unless you extract it first ("right-click the data source in the Data pane and choose **Extract Data**"). A plain `.twb` holds only the workbook, so the recipient also needs access to the data.

**Image.** "Select **Worksheet > Export > Image**", choose what to include in the Export Image dialog, and save as BMP, JPEG, PNG or SVG. **Worksheet > Copy > Image** puts the picture on the clipboard instead.

**PDF.** "Select **File > Print to PDF**." Choose the range: "**Entire Workbook**", "**Active Sheet**" or "**Selected Sheets**", a **Paper Size**, and **Show Selections** to keep the current selections in the PDF. (On a Mac: File > Print, then PDF > Save as PDF.)

**Publish to Tableau Server or Tableau Cloud.** "Select **Server > Publish Workbook**" (with a worksheet or dashboard tab active, not the Data Source tab), and sign in. "In the Publish Workbook dialog box, select the project, enter a name for the workbook, and add search tags." Then:
- **Permissions**: usually "accept the default project settings"
- **Data Sources**: "select Edit to change whether the data is embedded in the workbook or published separately"
- **Show Sheets as Tabs** for tab navigation, **Show Selections**, and **Include External Files** to package local files such as Excel or CSV with the workbook.

"Hiding sheets isn't a security measure": anyone with access can still reach hidden sheets.

> **Tableau Public:** Tableau Desktop Public Edition saves to the Tableau Public website or to your computer, but it can't publish to Tableau Server or Tableau Cloud. By default, viewers on Tableau Public can download a viz and its underlying data, which you can turn off in the viz settings. (Desktop Free Edition can't save to Tableau Public.)

### View and export underlying data

**View Data** shows the data behind a view or a mark. Open it:
- from a mark's tooltip ("select **View Data** from the tooltip menu", when command buttons are on)
- by right-clicking the view (except in text tables) and selecting **View Data**
- from the **Analysis** menu, or the **View Data** button next to the Search field in the Data pane (for a whole data source).

The window has tabs. "The **Summary** tab displays the dimensions that define the view and the aggregated measure or measures that make up the mark." The **Full Data** tab lists the rows themselves, for single-table data sources. Select **(All)** under **Show Fields** to see every field. "To export all of the data for the selected tab, click the **Download** button": it goes to a CSV file and "isn't limited to the number of rows currently displayed". The window itself shows up to 10,000 rows in Tableau Desktop.

**Export a sheet's data:**
- "**Worksheet > Export > Data**" exports the view's data, as an Access database (Windows) or a .csv file (Mac). The exported fields "come from the fields on the shelves of the sheet".
- "**Worksheet > Export > Crosstab to Excel**" exports the view as a table for Excel.
- **Worksheet > Copy > Data** or **Copy > Crosstab** copies to the clipboard.
- On the Data Source page, **Data > Export Data to CSV** exports the data source.

### Export to Microsoft PowerPoint

"Select **File > Export as PowerPoint**" and choose the sheets. "Selected sheets become static PNG images on separate slides", and "any filters currently applied in Tableau are reflected in the exported presentation". Story points export as separate slides. The slides are pictures: viewers can't interact with them, and they don't update with the data.

## At Driftlight

- The analyst sends the finance team a **`.twbx`** with the CSV-based workbook. They open it in Tableau without needing access to Driftlight's file share.
- The executive dashboard is **published to Tableau Server** with an extract data source and a nightly refresh, **Show Sheets as Tabs** off, and permissions from the Executives project.
- The weekly email includes a **PNG** of the line chart; the board pack is a **PDF** of selected sheets.
- When someone asks "which sessions are behind this bar?", the analyst uses **View Data** on the mark and **downloads** the full data as CSV.
- The quarterly review deck comes from **Export as PowerPoint** on the story, one slide per story point.

## Exam traps

<Callout title=".twbx vs. publishing">
  <p>A .twbx is a single file with the workbook and its local data, for someone who has Tableau. Publishing puts the workbook on Tableau Server or Tableau Cloud for viewers in a browser, with permissions and (with a live connection or refreshed extract) current data.</p>
</Callout>

<Callout title="Summary vs. full data">
  <p>View Data's Summary tab shows the aggregated values of the marks (one row per mark). The full data shows the underlying rows. A question about "the individual records behind a bar" wants the full data.</p>
</Callout>

<Callout title="Export Data vs. Crosstab to Excel">
  <p>Worksheet &gt; Export &gt; Data exports the data behind the view (Access on Windows, CSV on Mac). Worksheet &gt; Export &gt; Crosstab to Excel exports the table as laid out in the view.</p>
</Callout>

<Callout title="PowerPoint slides are static">
  <p>File &gt; Export as PowerPoint makes one static image per sheet. Filters in effect are applied, but nothing is interactive or live.</p>
</Callout>

<Callout title="Hidden is not secure">
  <p>Hiding sheets before publishing tidies the tabs, but hidden sheets aren't protected. Use permissions to control access.</p>
</Callout>
