## Goal

Every number in a view depends on two choices: the **aggregation** (SUM, AVG, …) and the **dimensions** in the view, which decide how the rows are grouped (the level of detail). In this challenge you change both, one at a time, in Tableau Desktop Public Edition (Tableau Public for short), and watch the same measure take different values.

Download this file:

`sessions_2025.csv` has one row per viewing session in 2025, with the minutes watched. You also need **Tableau Desktop Public Edition**, free from Tableau Public's website.

## Steps

<Step id="one-mark">
  Open Tableau Public, connect to `sessions_2025.csv` (**Text file** in the Connect pane) and open **Sheet 1**. Drag **Minutes Watched** to Columns. Tableau applies the measure's default aggregation, which it set when you connected: the pill says `SUM(Minutes Watched)`. With no dimension in the view, all the rows form one group, so there's a single bar. Hover over it to read the total.
</Step>

<Step id="split-by-device">
  Drag **Device** to Rows. Tableau computes the sum again, once per device: one bar per member, plus a **Null** bar for the sessions with no device recorded. `SUM` is additive, so the bars add up to the total from the previous step. In SQL terms, you've added Device to the `GROUP BY`.
</Step>

<Step id="device-on-color">
  Drag **Device** from Rows to **Color** on the Marks card. You're back to one bar, now split into coloured segments: "Encoding a dimension by a property on the Marks card (such as Color or Size) increases the number of marks without adding headers." Every dimension in the view is part of the level of detail, wherever you put it. Drag Device back to Rows.
</Step>

<Step id="average-pill">
  Open the menu on the `SUM(Minutes Watched)` pill and choose **Average** under **Measure**. Each bar now shows the typical session length on that device. These bars don't add up to anything: averages per device don't combine into the overall average. The change applies to this pill only.
</Step>

<Step id="default-aggregation">
  In the Data pane, right-click **Minutes Watched** and choose **Default Properties > Aggregation > Average**. Open a new sheet and drag Minutes Watched to Columns: the new pill starts as `AVG(Minutes Watched)`. A default changes every new use of the field in the workbook. Set it back to **Sum** afterwards.
</Step>

<Step id="disaggregate">
  On a new sheet, put **Minutes Watched** on Columns, then open the **Analysis** menu and clear **Aggregate Measures**. The view is now **disaggregated**: Tableau "displays a separate mark for every data value in every row", one mark per session. Select **Aggregate Measures** again to go back to one mark.
</Step>

<Callout title="Public vs. Desktop">
  <p>Aggregations, Default Properties and Aggregate Measures work the same in Tableau Public. One difference from the paid Desktop: you can't set default aggregations for **published data sources**, which Tableau Public can't connect to.</p>
</Callout>

## Exam angle

- Numeric measures default to **SUM**, set when you connect. Change it for one view on the pill's menu, or for every new use with **Default Properties > Aggregation**.
- Adding a dimension anywhere in the view (Rows, Columns, Color, Size, Label, Detail) adds to the level of detail: more marks, smaller values.
- `SUM` and `COUNT` pieces add back up to the total. `AVG`, `MEDIAN`, `MIN`, `MAX` and `COUNTD` pieces don't.
- Clearing **Analysis > Aggregate Measures** shows one mark per row. It isn't a filter and it isn't adding a dimension.
- The [Granularity simulator](/build/sim/granularity) lets you add and remove dimensions and watch the marks change.
